## 公众号稿件风格

以 `qtcloud-media-cli/index.md`（已定时发布版）为基准：

- 标题只进草稿 title 字段，正文不用 H1（render 已自动跳过开头 H1）；标题不夹命令名
- 小节名用短实名词（API、使用），不用宽泛词（功能、使用方法）
- 代码块逐条独立，前面用一句自然语句说明（「只排版：」），不在代码里写 # 注释
- 正面陈述，不用「不是 X」式否定句起手
- 正文不放 GitHub 等外链（公众号里点不开），反馈走仓库 issue
- 摘要一句短句
